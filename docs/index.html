About SuperScanner

SuperScanner is an independent companion for people who use Supernote devices. Its offline sample uses fictional pages and prepared text. Live capture and recognition require a compatible device, a trusted local network, and an OpenAI provider setup.

Recognition can use ChatGPT plan sign-in or an OpenAI API key. Before the first live recognition upload, the app explains what it sends to OpenAI and asks for consent. Experimental Supernote Linking transfers text over local Wi-Fi without transport encryption.
